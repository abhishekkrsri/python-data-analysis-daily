# Day 06 - Python Practice

Today I continued learning advanced Python fundamentals and practiced 5 new concepts with working examples.

## Topics Covered

### 1. Variable Scope
- Learned the difference between global and local variables.
- Understood how variable scope works inside and outside functions.
- Practiced using variables with the same name in different scopes.

### 2. `*args`
- Learned how to pass a variable number of positional arguments to a function.
- Understood that `*args` collects the arguments into a tuple.
- Practiced calculating the total of multiple values.

### 3. `**kwargs`
- Learned how to pass a variable number of keyword arguments to a function.
- Understood that `**kwargs` collects the arguments into a dictionary.
- Practiced working with dictionary keys and values using `.items()`.

### 4. `map()`
- Learned how to apply a function to every item in a list.
- Practiced transforming a list of prices.
- Understood how `map()` works with functions and `list()`.

### 5. `filter()`
- Learned how to select items from a list based on a condition.
- Practiced filtering prices greater than a specific value.
- Understood the difference between `map()` and `filter()`.
